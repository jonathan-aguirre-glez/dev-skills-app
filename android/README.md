# Android Module

This is the Android (Kotlin + Jetpack Compose) module for the Dev Skills App.

## Setup

Open the `android/` folder in Android Studio to set up and run the Android app.

## Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Networking**: Retrofit + OkHttp
- **Dependency Injection**: Hilt

> **Note**: This module is a placeholder and will be fully set up with Android Studio.
